# 🧪 `@kurone-kito/example-cli`

The example CLI app for the Node.js apps.

## System Requirements

- Node.js: Any of the following versions
  - Iron LTS (`^20.18.x`)
  - Jod LTS (`^22.x.x`)
  - Krypton LTS (`^24.x.x`)
  - Latest (`>=25.x.x`)

## Usage

```sh
pnpm exec @kurone-kito/example-cli
```
